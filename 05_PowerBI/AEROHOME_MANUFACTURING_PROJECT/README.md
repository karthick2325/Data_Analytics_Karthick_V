# Novitech Manufacturing Analytics – Power BI Dashboard

## 📊 Project Overview

**Novitech Manufacturing Analytics Dashboard** is an interactive **Power BI analytics project** designed to monitor and analyze manufacturing operations, production performance, quality, finance, procurement, supply chain, and workforce efficiency.

The dashboard helps management identify **business trends, operational issues, cost drivers, quality problems, supplier performance, and supply chain risks** through interactive KPIs and visual reports.

---

## 🎯 Objectives

- Monitor overall manufacturing performance
- Analyze production and plant efficiency
- Track product quality and defects
- Monitor machine downtime and operational performance
- Analyze manufacturing costs and financial performance
- Evaluate procurement and supplier performance
- Identify delayed purchase orders
- Monitor raw material availability
- Identify supply chain risks
- Compare operator and shift performance
- Support data-driven business decisions

## 🗂️ Data Model

The project uses a structured manufacturing data model containing **fact and dimension tables** to support efficient analysis across different business areas.

### Dimension Tables

- `dim_products`
- `dim_machines`
- `dim_materials`
- `dim_plants`
- `dim_suppliers`
- `dim_operators`
- `bridge_bill_of_materials`

### Fact Tables

- `fact_production`
- `fact_downtime`
- `fact_quality`
- `fact_purchase_orders`

The data model enables cross-analysis between **production, quality, operations, procurement, suppliers, materials, and workforce performance**.
