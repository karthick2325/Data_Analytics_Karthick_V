# 🛍️ TrendKart – Sales Dashboard

> **Interactive Sales Analysis Dashboard using Microsoft Excel**

![TrendKart Sales Dashboard](DASHBOARD/Dashboard.jpeg)

## 🎯 Objective

To analyze **TrendKart sales data** and develop an interactive Excel dashboard that provides clear insights into **Sales, Profit, Orders, Customers, Average Order Value, Sub-Categories, and Monthly Sales Performance**.

## 🛠️ Tools Used

- Microsoft Excel
- Data Cleaning
- Pivot Tables
- Pivot Charts
- Slicers
- Data Analysis
- Data Visualization
- Dashboard Design

## 💡 Key Insights

- Total sales reached approximately **₹92.27 Lakhs**.
- Total profit generated is approximately **₹18.05 Lakhs**.
- A total of **3,000 orders** are represented in the dashboard.
- The dashboard includes **850 customers**.
- The **Average Order Value (AOV)** is approximately **₹3,075.73**.
- **October** recorded the highest monthly sales at approximately **₹15.19 Lakhs**.
- Regional performance can be compared using the **Region slicer**.
- Sub-category-level Sales, Quantity, and Profit can be analyzed using the **Sub Category slicer**.
- Monthly Sales and Profit comparison helps identify changes in business performance throughout the year.

## 🎛️ Interactive Dashboard Features

The dashboard includes interactive **Excel Slicers** that allow users to dynamically filter the analysis by:

- Region
- Sub Category
- Invoice Date

All relevant dashboard data updates based on the selected filters.

4. **Sub Category Filter**

5. **Sub-Category Sales, Quantity & Profit Table**
