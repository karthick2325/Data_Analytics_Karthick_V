# 🛒 FreshMart – Retail Sales Dashboard

> **Interactive Retail Sales Analysis Dashboard using Microsoft Excel**

![FreshMart Sales Dashboard](Dashboard/Dashboard.png)

## 🎯 Objective

To analyze **FreshMart retail sales data** and develop an interactive Excel dashboard that provides clear insights into **Sales, Profit, Orders, Customers, Average Order Value, Regions, Categories, and Monthly Sales Performance**.

## 🛠️ Tools Used

- Microsoft Excel
- Data Cleaning
- Pivot Tables
- Pivot Charts
- Slicers
- Data Analysis
- Data Visualization
- Dashboard Design

## 🎛️ Interactive Dashboard Features

The dashboard includes interactive **Excel Slicers** that allow users to dynamically filter the analysis by:

- Region
- Category
- Transaction Date

All charts and KPI values update based on the selected filters.
