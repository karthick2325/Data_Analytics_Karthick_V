# 🛒 FreshMart – Retail Sales Dashboard

> **Interactive Retail Sales Analysis Dashboard using Microsoft Excel**

![Dashboard](Dashboard/Dashboard.png)

## 🎯 Objective

To analyze **FreshMart retail sales data** and create an interactive dashboard that provides clear insights into **Sales, Profit, Quantity, Orders, Regions, Categories, Payment Methods, Discounts, Returns, Customer Membership, Sales Channels, and Store Performance**.

## 🛠️ Tools Used

* Microsoft Excel
* Data Cleaning
* Pivot Tables
* Pivot Charts
* Data Visualization
* Dashboard Design

## 💡 Key Insights

* Total sales reached approximately **₹28.93 Lakhs**.
* Total profit reached approximately **₹7.37 Lakhs** with a **25.49% profit margin**.
* The dashboard recorded **2,500 orders** with **9,823 total quantity sold**.
* **South region** contributes the highest share of regional sales at **65%**.
* **In-Store** is the leading sales channel with **69%** of sales.
* **After noon** has the highest order value compared with other order time periods.
* Category, product, store, discount, return, and customer membership performance can be compared through the dashboard.
* Target vs actual store performance helps identify differences between store targets and achieved sales.
* Payment mode and sales channel analysis provide additional insights into customer purchasing behavior.
